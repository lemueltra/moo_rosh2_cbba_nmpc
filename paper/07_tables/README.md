# `07_tables`

Tabelas do artigo, referenciadas a partir de `05_sections/`.

**Não existe gerador de tabela.** Esta pasta é preenchida à mão, com uma
condição: **toda célula numérica é um marcador de backfill** (`{{R:MET-xxx}}`),
resolvido por `scripts/backfill_numbers.py` a partir de
`03_evidence/results_manifest.json`. Um número digitado à mão aqui é o mesmo
defeito que um número digitado à mão na prosa.

Quando um gerador existir (fase posterior), esta pasta passa a ser derivada e
editar à mão vira erro. Enquanto não existir, escrever "gerada por script" num
relatório de verificação é fabricar evidência.
